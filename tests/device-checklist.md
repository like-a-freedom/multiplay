# Проверка на реальном устройстве (iPhone 12 Pro Max, Safari)

e2e (`npm run test:e2e`) проходит на движке Safari в эмуляции iPhone, но он не заменяет
проверку на телефоне. Перед игрой с сыном пройти список ниже и записать фактическую
версию iOS (сама модель телефона совместимость не подтверждает).

## Как открыть на телефоне

Установка PWA требует HTTPS. Варианты:

1. **Статический HTTPS-хостинг** (по PRD): выложить `npm run build` (каталог `dist/`) на любой
   статический HTTPS-хост, открыть адрес в Safari на телефоне.
2. **Быстрая проверка без установки**: `npm run dev -- --host`, открыть `http://<ip-мака>:5173`
   в Safari на телефоне (той же Wi-Fi сети). Проверить можно всё, кроме установки PWA
   и офлайн-режима — они требуют HTTPS.

## Чеклист (PRD §7)

- [ ] Записать версию iOS: ____________
- [ ] Установка: «Поделиться» → «На экран “Домой”» → иконка и название на домашнем экране.
- [ ] Сообщение «Готово без интернета» появляется после первого запуска с сетью.
- [ ] Авиарежим: установленная PWA открывается и показывает карточки без сети.
- [ ] Восстановление миссии: закрыть посередине миссии, открыть снова — сделанные попытки
      на месте, награда не начислена дважды.
- [ ] Ввод: появляется цифровая клавиатура, ответ принимается кнопкой и Enter.
- [ ] Увеличение текста до 200% (Настройки → Основные → Универсальный доступ → Крупный текст):
      пример и поле ответа читаются без обрезки, экран прокручивается.
- [ ] Безопасные области: кнопки не перекрываются домашним индикатором и клавиатурой.
- [ ] Обновление PWA: выложить новую сборку, убедиться, что предложение обновиться появляется
      между миссиями и прогресс не теряется.
- [ ] Сон/пробужение и смена ориентации не ломают экран карточки.

## Заметки

Прогресс привязан к браузерному контексту и адресу сайта: перенос из Safari в
установленную PWA или на другой адрес не поддерживается, резервной копии нет
(политика WebKit по хранилищу допускает вытеснение данных).
