# Космическая экспедиция: дизайн-бриф

**Статус:** целевой UX для следующей итерации; текущую реализацию описывает `DESIGN.md`. **Режим:** Operate — ребёнок решает примеры, а космос показывает последствия его действий. **Устройство:** iPhone 12 Pro Max, портретная PWA; язык интерфейса — русский.

## Задача и дизайн-идея

Сыну 10 лет. Он должен охотно запускать короткие миссии, отвечать самостоятельно и видеть накопительный результат без страха ошибки. Визуальная идея: **«мой корабль исследует мой космос»**. На главном экране корабль и маршрут делают очередной шаг видимым; на карточке всё подчинено примеру; на карте постепенно появляется настоящее созвездие из 66 фактов. Образ — небольшой исследовательский корабль с характером в движении, без лица, грусти и наказания.

У приложения два разных типа прогресса. **Синий маршрут корабля** отражает XP и уровни: +10 XP за миссию, обычный дневной предел 30 XP, возможны бонусы серии, уровень `1 + floor(XP / 100)`. **Золотые звёзды знаний** отражают только подтверждённое воспроизведение фактов спустя ≥7 дней; их 66, они не исчезают. Подлежащие повторению факты отмечаются отдельно. Это особенно важно в первую неделю, когда XP уже растёт, а звёзд ещё может не быть. `+0 XP` не двигает корабль и объясняется словами; завершённая практика всё равно признаётся. После 66-й звезды экспедиция завершается один раз, затем остаются повторения и свободная практика.

## Сценарий и иерархия

| Момент | Что видит ребёнок | Что меняется |
| --- | --- | --- |
| Главная | Корабль над компактным маршрутом, `XP / уровень`, `звёзды из 66`, одно главное действие. Карта видна фрагментом; отчёт взрослого вторичен. | После награды корабль уже стоит на новой точке; световой пролёт был показан на финише миссии и не проигрывается повторно на главной. Название действия остаётся `Играть`, `Повторить` или `Свободная практика` по текущим правилам. |
| Старт | Кнопка отвечает на касание; корабль летит к точке. | Карточка появляется без экрана загрузки. Переход ≤240 мс, при reduced motion — сразу. Повторное нажатие не запускает вторую миссию. |
| Карточка | Один пример, поле ответа и понятная кнопка; космос остаётся фоном. | Успех — спокойная зелёная карточка и `Верно`; ошибка — тёплая янтарная карточка, верный ответ и объяснение. Частиц поверх вопроса нет. |
| Финиш | Итог миссии, конкретная награда и её причины, текущий уровень, звёзды отдельно. | XP считает вверх один раз; на этом же экране корабль проходит заработанный участок пути со световым следом. При `+0 XP` число статично, путь не движется и показана причина. Кнопки доступны без ожидания эффекта. |
| Новая звезда | На ответе — краткое текстовое сообщение; при первом открытии карты загорается именно соответствующий факт и короткая линия соединяет его с нейтральным навигационным маяком. | Несколько новых звёзд показываются без потери ни одной; линия — только эффект появления, она не меняет постоянный рисунок карты. После перезагрузки анимация не воспроизводится. |
| 66-я звезда | В финише — та же карта из 66 фактов, полностью открытая, и один праздничный эффект. | Событие происходит только после завершения миссии и не повторяется при обычных открытиях карты. |

## Визуальная система

Сохранить «Expedition Logbook»: тёмное пространство `#0B1020`, светлая карточка `#F7FAFF`, синий маршрут `#175CD3`, золото настоящей звезды `#F9BA43`, зелёный успех `#E0F4E8`, янтарная помощь `#FFF3DD`. Корабль — оригинальный SVG с узнаваемым силуэтом: при запуске слегка разворачивается и ускоряется, после награды мягко «садится» на новую точку, при ошибке не меняет характер. Маршрут — изогнутая орбитальная дуга с десятью тихими ориентирами на 10, 20, …, 100 XP; 0 XP — старт перед ними. Корабль показывает точное положение между ориентирами, а при переходе уровня проходит конец текущей дуги и начало следующего сектора на экране финиша. На главной экран строится вокруг корабля и следующей точки, без бесконечного мерцания. Карта появляется до длинного объяснения правил. Карта использует существующий `StarGlyph` и детерминированные позиции 12/22/32; тот же рисунок должен быть в финале вместо отдельной сетки. «Загорание» звезды означает появление золотого заполнения и короткое изменение масштаба, без внешнего неонового ореола из `DESIGN.md`. Новые декоративные точки не выглядят как заработанные звёзды.

## Inspira UI и стек

Подключить **Tailwind CSS v4** к Vite и использовать компоненты Inspira как копируемый, адаптируемый исходный код; это [официальная модель библиотеки](https://docs.inspira-ui.com/docs/en/getting-started/installation). Сохранить существующие CSS-токены как источник цвета и размеров. Начать с импорта theme/utilities без Preflight, чтобы текущие поля и кнопки не изменились из-за глобального reset; это [поддерживается Tailwind](https://tailwindcss.com/docs/preflight). В новых компонентах использовать utility-классы, а в старых scoped CSS — существующие переменные без `@apply`. Перед выпуском проверить версию iOS/Safari устройства: Tailwind v4 заявляет поддержку Safari 16.4+ ([совместимость](https://tailwindcss.com/docs/compatibility)). Разработка может идти на WebKit; если реальный телефон работает на более старой версии, до публикации потребуется обновить iOS или выбрать совместимое оформление.

Взять четыре осмысленных примитива из [Inspira UI](https://github.com/unovue/inspira-ui/tree/04c57ab62b9713872ebbf68988dff1836ed3d764): [Ripple Button](https://docs.inspira-ui.com/docs/en/components/buttons/ripple-button) для главного действия, [Animated Beam](https://docs.inspira-ui.com/docs/en/components/special-effects/animated-beam) для однократного светового маршрута, [Number Ticker](https://docs.inspira-ui.com/docs/en/components/text-animations/number-ticker) для полученного XP, [Confetti](https://docs.inspira-ui.com/docs/en/components/special-effects/confetti) только для завершения всей экспедиции. Адаптации обязательны: Ripple центрируется при активации с клавиатуры и очищает таймеры; Animated Beam вместо исходного бесконечного цикла делает один пролёт с явными Vue-импортами и корректной инициализацией DOM-элементов; Number Ticker получает `decimalPlaces=0`, а доступный текст сразу сообщает итоговое число; Confetti запускается вручную один раз и отключается при reduced motion. Если модуль конфетти загружается асинхронно, запуск должен дождаться загрузки и отмениться при уходе с экрана. В скопированных классах заменить исходные `bg-background`/`text-primary` на токены проекта. Для движения корабля допустим `motion-v`. Исходники закрепить на указанном коммите Inspira и сохранить MIT-уведомление. Не подключать всю галерею эффектов или неиспользуемые пакеты.

## Поведение, доступность и проверка

Эффекты не блокируют ввод, переход или продолжение миссии. Уважать `prefers-reduced-motion`: статичный конечный кадр остаётся информативным, частицы и перелёты отключаются ([W3C](https://www.w3.org/WAI/WCAG21/Understanding/animation-from-interactions)). Все числа и события названы текстом; фокус после запуска попадает в поле ответа, после ответа — на «Продолжить». Сохранить касаемые области ≥48 CSS px, ввод с системной клавиатуры, работу при 200% текста и без сети. Не добавлять звук, циклический фон, валюту или новые учебные правила.

Проверить до и после: iPhone/WebKit, ширины 428 и 320 px, 200% текста, reduced motion, `0/1/66` звёзд, `+0 XP`, переход уровня, несколько звёзд за миссию, повторение, прерывание и перезагрузку, офлайн. На реальном телефоне показать сыну две короткие миссии: может ли он без объяснений различить XP и звёзды, увидеть изменение маршрута и продолжить после ошибки. Это проверка дизайнерской гипотезы, не изменение критерия освоения.
